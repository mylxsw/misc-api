接口英文名：draft\_update

本接口用于修改图文或图片消息草稿

## [#](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#_1-%E8%B0%83%E7%94%A8%E6%96%B9%E5%BC%8F) 1. 调用方式

### [#](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#HTTPS-%E8%B0%83%E7%94%A8) HTTPS 调用

### [#](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#%E4%BA%91%E8%B0%83%E7%94%A8) 云调用

-   本接口不支持云调用。

### [#](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#%E7%AC%AC%E4%B8%89%E6%96%B9%E8%B0%83%E7%94%A8) 第三方调用

-   本接口支持第三方平台代商家调用。

-   服务商获得其中之一权限集授权后，可通过使用 [authorizer\_access\_token](https://developers.weixin.qq.com/doc/oplatform/developers/dev/AuthorizerAccessToken) 代商家进行调用，具体可查看 [第三方调用](https://developers.weixin.qq.com/doc/oplatform/Third-party_Platforms/2.0/Before_Develop/call_interface) 说明文档。

### [#](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#%E6%9F%A5%E8%AF%A2%E5%8F%82%E6%95%B0-Query-String-Parameters) 查询参数 `Query String Parameters`

| 参数名 | 类型 | 必填 | 示例 | 说明 |
|--------------|--------|-----|--------------|-----------------------------------------------|
| access_token | string | 是 | ACCESS_TOKEN | 接口调用凭证，可使用 [access_token](https://developers.weixin.qq.com/doc/subscription/api/base/api_getaccesstoken)、[authorizer_access_token](https://developers.weixin.qq.com/doc/oplatform/openApi/ticket-token/api_getauthorizeraccesstoken) |

### [#](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#%E8%AF%B7%E6%B1%82%E4%BD%93-Request-Payload) 请求体 `Request Payload`

| 参数名 | 类型 | 必填 | 示例 | 说明 |
|----------|--------|-----|----------|---------------------------------------|
| media_id | string | 是 | MEDIA_ID | 要修改的图文消息的id |
| index | number | 是 | 0 | 要更新的文章在图文消息中的位置（多图文消息时，此字段才有意义），第一篇为0 |
| articles | [object](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#Body__articles) | 是 | - | 图文信息 |

### [#](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#Body-articles-Object-Payload) Body.articles `Object Payload`

图文信息

| 参数名 | 类型 | 必填 | 说明 |
|---------------------|--------|-----|------------------------------------------------------------------------------------------------------------------------------|
| article_type | string | 否 | 文章类型，分别有图文消息（news）、图片消息（newspic），不填默认为图文消息（news） |
| title | string | 是 | 标题 |
| author | string | 否 | 作者 |
| digest | string | 否 | 图文消息的摘要，仅有单图文消息才有摘要，多图文此处为空。如果本字段为没有填写，则默认抓取正文前54个字。 |
| content | string | 是 | 图文消息的具体内容，支持HTML标签，必须少于2万字符，小于1M，且此处会去除JS,涉及图片url必须来源 "上传图文消息内的图片获取URL"接口获取。外部图片url将被过滤。 图片消息则仅支持纯文本和部分特殊功能标签如商品，商品个数不可超过50个 |
| content_source_url | string | 否 | 图文消息的原文地址，即点击“阅读原文”后的URL |
| thumb_media_id | string | 否 | 图文消息的封面图片素材id（必须是永久MediaID） |
| need_open_comment | number | 否 | 是否打开评论，0不打开(默认)，1打开 |
| only_fans_can_comment | number | 否 | 是否粉丝才可评论，0所有人可评论(默认)，1粉丝才可评论 |
| image_info | [object](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#Body__articles__image_info) | 是 | 图片消息里的图片相关信息，图片数量最多为20张，首张图片即为封面图 |
| cover_info | [object](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#Body__articles__cover_info) | 否 | 封面信息，图文消息（news）和图片消息（newspic）均适用 |
| product_info | [object](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#Body__articles__product_info) | 否 | 商品信息 |

### [#](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#Body-articles-image-info-Object-Payload) Body.articles.image\_info `Object Payload`

图片消息里的图片相关信息，图片数量最多为20张，首张图片即为封面图

| 参数名 | 类型 | 必填 | 说明 |
|------------|----------|-----|------|
| image_list | [objarray](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#Body__articles__image_info__image_list%3CArray%3E) | 是 | 图片列表 |

### [#](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#Body-articles-image-info-image-list-Array-Object-Payload) Body.articles.image\_info.image\_list(Array) `Object Payload`

图片列表

| 参数名 | 类型 | 必填 | 说明 |
|--------------|--------|-----|----------------------------|
| image_media_id | string | 是 | 图片消息里的图片素材id（必须是永久MediaID） |

### [#](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#Body-articles-cover-info-Object-Payload) Body.articles.cover\_info `Object Payload`

封面信息，图文消息（news）和图片消息（newspic）均适用

| 参数名 | 类型 | 必填 | 说明 |
|-----------------|----------|-----|--------------------------------------------------------------------|
| crop_percent_list | [objarray](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#Body__articles__cover_info__crop_percent_list%3CArray%3E) | 否 | 封面裁剪信息。以图片左上角（0,0）、右下角（1,1）建立平面坐标系，裁剪区域左上角坐标填入 x1、y1，右下角坐标填入 x2、y2 |

### [#](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#Body-articles-cover-info-crop-percent-list-Array-Object-Payload) Body.articles.cover\_info.crop\_percent\_list(Array) `Object Payload`

封面裁剪信息。以图片左上角（0,0）、右下角（1,1）建立平面坐标系，裁剪区域左上角坐标填入 x1、y1，右下角坐标填入 x2、y2

| 参数名 | 类型 | 必填 | 说明 |
|-------|--------|-----|----------------------------------------------------------------|
| ratio | string | 否 | 裁剪比例。图文消息（news）仅支持“2.35_1”“1_1”；图片消息（newspic）支持“1_1”“16_9”“2.35_1” |
| x1 | string | 否 | 裁剪区域左上角的横坐标 |
| y1 | string | 否 | 裁剪区域左上角的纵坐标 |
| x2 | string | 否 | 裁剪区域右下角的横坐标 |
| y2 | string | 否 | 裁剪区域右下角的纵坐标 |

### [#](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#Body-articles-product-info-Object-Payload) Body.articles.product\_info `Object Payload`

### [#](https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html#Body-articles-product-info-footer-product-info-Object-Payload) Body.articles.product\_info.footer\_product\_info `Object Payload`
